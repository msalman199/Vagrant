## 🎯 Overview

> 🧪 **Lab Environment:** A Linux-based system, used to practice file system management with bash scripting.

In this lab, you learned essential Linux file system management tasks: navigating and creating directories and files, controlling access with permissions and ownership, and automating cleanup of old files.

---

## 🏆 Key Accomplishments

In this lab, you have learned to:

- 📁 Navigate and create directories and files using bash scripting
- 🔐 Set file permissions and ownership with `chmod` and `chown`
- 🧹 Automate file cleanup based on age using `find` and `rm`

---

## 🧠 Key Concepts

| 🔑 Concept | 📖 Description |
|---|---|
| **Bash Scripting** | Using bash scripts to navigate and create directories and files |
| **`chmod`** | Command for setting file permissions |
| **`chown`** | Command for setting file ownership |
| **Access Control** | Ensuring files are accessible only as intended through proper permissions and ownership |
| **`find`** | Command used to locate files, here based on their age |
| **`rm`** | Command used to remove files, here for age-based cleanup |
| **Automated Cleanup** | Removing files by age with a script to maintain a clean working environment |

## ✅ Conclusion

In this lab, you have learned essential Linux file system management tasks, including:

These skills are crucial for managing files, ensuring proper access control, and maintaining a clean working environment in Linux-based systems. By completing this lab, you can now automate the process of organizing and securing files within your Linux system using simple bash scripts.
