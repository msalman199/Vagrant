## 🎯 Overview

> 🧪 **Lab Environment:** A Vagrant-managed virtual machine, used as a safe and isolated space to practice automation and system management tasks with shell scripting.

In this lab, you set up a Vagrant environment and learned how to create and run shell scripts. The Vagrant virtual machine provided a safe and isolated environment to practice automation and system management tasks. This foundational knowledge is useful for automating administrative tasks and managing systems efficiently.

---

## 🏆 Key Accomplishments

By completing this lab, you have:

- 📦 Set up a virtual machine using Vagrant
- 📝 Written a shell script to display system information
- 🧪 Run and tested the script in a Vagrant-managed environment

## 🧠 Key Concepts

| 🔑 Concept | 📖 Description |
|---|---|
| **Vagrant** | A tool for creating and managing virtual machine environments |
| **Virtual Machine (VM)** | An isolated environment that provides a safe place to practice system tasks |
| **Shell Script** | A script of shell commands used to automate administrative and system management tasks |
| **System Information Script** | A shell script written in this lab to display information about the system |
| **Automation** | Using scripts to perform administrative tasks efficiently and repeatably |
| **Isolated Environment** | A sandboxed setup where scripts can be run and tested without risk to the host |
| **DevOps Workflow** | A broader practice of automating and managing systems, for which these skills form the basis |
